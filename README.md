# 情报局跟单宝 用户使用说明

情报局跟单宝是一套 KOL交易信号跟单工具。它可以监听指定KOL里的交易信号，并按照你在网页后台设置的规则，在 Binance 或 Bybit 合约账户中执行订单。

本说明主要写给普通用户，按步骤操作即可。

---

## 1. 程序能做什么

- 监听 KOL 交易信号。
- 支持 Binance 和 Bybit。
- 支持模拟盘和实盘。
- 支持多入场、多止盈、止损。
- 网页后台可以配置账号、交易员、风险金额、查看持仓、历史记录和日志。
- 配置、密钥、数据库、日志会保存在服务器上，更新容器后不会丢失。

---

## 2. 使用前准备

你需要准备：

1. 一台 Linux 服务器。
2. 服务器开放 `8000` 端口。
3. Discord Token。
4. Binance 或 Bybit 的 API Key 和 Secret。
5. 交易所账户需要开通合约交易。

建议：

- 新用户先使用模拟盘或测试网。
- API Key 不要开启提币权限。
- 实盘建议使用子账户，不要直接使用主账户。

---

## 3. 一键安装

在服务器终端执行：

```bash
curl -O https://raw.githubusercontent.com/zhong1424535530-pixel/qingbaoju-bot/main/install.sh && chmod +x install.sh && ./install.sh
```

脚本会自动完成：

- 检查并安装 Docker。
- 创建数据目录。
- 拉取最新镜像。
- 启动 `discord-follower` 容器。

安装完成后，浏览器打开：

```text
http://服务器IP:8000/
```

如果打不开网页，请先检查服务器安全组、防火墙是否放行 `8000` 端口。

---

## 4. 登录后台

首次登录默认账号密码：

```text
账号：admin
密码：admin
```

登录后建议马上到后台的安全设置里修改账号密码。

---

## 5. 配置 Discord

进入网页后台后：

1. 打开“配置”页面。
2. 填写 Discord Token。
3. 保存。
4. 点击 Discord 开关，等待连接成功。

如果连接失败，请检查：

- Token 是否正确。
- Discord 账号是否能访问对应交易员频道。
- 服务器网络是否能连接 Discord。

---

## 6. 配置交易所

后台支持 Binance 和 Bybit，每个交易所都有模拟盘/测试网和实盘配置。

操作步骤：

1. 选择交易所。
2. 选择模式：`模拟/测试网` 或 `实盘`。
3. 填写 API Key 和 API Secret。
4. 保存。
5. 点击对应连接开关。

建议先连接模拟盘或测试网，确认程序正常后再考虑实盘。

---

## 7. 添加交易员频道

在后台添加频道时，需要填写：

- 交易员：选择你要跟踪的交易员。
- 交易所：选择 Binance 或 Bybit。
- 模式：选择模拟/测试网或实盘。
- 风险金额：每笔策略愿意承担的风险金额。
- 备注：方便自己识别，可不填。
- 启用状态：开启后程序才会监听。

风险金额说明：

如果风险金额填写 `30U`，程序会根据入场价和止损价计算仓位。简单理解就是：如果这笔单止损了，理论上亏损接近 `30U`。实际结果会受到滑点、手续费、成交价格等影响。

---

## 8. 查看持仓、历史和日志

后台主要页面：

- 持仓：查看当前未平仓和未成交订单。
- 历史：查看已平仓、已取消订单和盈亏记录。
- 日志：查看程序运行情况、连接状态、报错原因。
- 配置：管理 Discord、交易所、频道和安全设置。

如果遇到问题，优先看“日志”页面。

也可以在服务器上查看容器日志：

```bash
docker logs -f discord-follower
```

## 10. 数据保存在哪里

程序数据默认保存在服务器：

```text
/opt/discord-follower/data
```

里面主要有：

```text
config_store.json       普通配置
exchange.env            交易所 API Key/Secret
binance_follower.db     数据库
logs/                   日志
```

这些文件不会打包进镜像，而是挂载到容器里使用。所以更新容器时，正常不会丢失数据。

请不要随便删除：

```text
/opt/discord-follower/data/config_store.json
/opt/discord-follower/data/exchange.env
/opt/discord-follower/data/binance_follower.db
```

删除后会导致配置、密钥或历史记录丢失。

## 11. 重置登录密码

如果忘记网页后台密码，在服务器执行：

```bash
docker exec -it discord-follower python3 reset_password.py
```

执行后会重置为：

```text
账号：admin
密码：admin
```

登录后请重新修改密码。

## 12. 常见问题

### 网页打不开

检查：

- 服务器是否正常运行。
- Docker 容器是否启动。
- 服务器是否开放 `8000` 端口。

查看容器状态：

```bash
docker ps
```

查看日志：

```bash
docker logs -f discord-follower
```

### Discord 连接不上

检查：

- Discord Token 是否正确。
- Discord 账号是否被限制。
- 服务器网络是否能访问 Discord。
- 当前账号是否有对应频道权限。

### 交易所连接失败

检查：

- API Key 和 Secret 是否填写正确。
- 是否选择了正确模式：模拟/测试网或实盘。
- API Key 是否有合约交易权限。
- API Key 是否被 IP 白名单限制。

### 下单失败

常见原因：

- 账户余额不足。
- 双向持仓未开启（常见问题）
- 交易对不存在或暂时不能交易。
- 下单数量低于交易所最小要求。
- 止损价和入场价过近。
- Binance 账户模式不符合要求。

请先查看“日志”页面，日志里通常会显示具体原因。

### 为什么交易员发 PEPE，程序下的是 1000PEPE

部分 meme 币在交易所里的真实合约名称带倍数，例如：

```text
PEPE -> 1000PEPEUSDT
SATS -> 1000SATSUSDT
```

程序会尽量自动匹配交易所真实合约名称，这是正常现象。

### 盈亏和交易所显示不完全一致

可能原因：

- 交易所实际成交价和策略入场价不完全一样。
- 有手续费、滑点。
- 多入场、多止盈时，程序会按本地记录计算展示。

最终资金变化以交易所实际记录为准。

### 手动在交易所平仓后，程序没同步

建议尽量在程序后台里操作平仓或取消订单。  
如果直接去交易所手动操作，程序本地状态可能无法完全同步。


### 日志里提示 Discord 临时断开

如果日志显示 Discord 临时断开并自动重连，通常属于正常网络波动。  
如果长时间无法恢复，再检查 Token、网络和 Discord 状态。

## 13. 安全建议

- API Key 不要开启提币权限。
- 实盘建议使用子账户。
- 不要把 `exchange.env` 发给别人。
- 不要把服务器密码、后台密码发给别人。
- 首次登录后立刻修改默认密码。
- 新交易员、新策略建议先用模拟盘观察。

---

## 14. 风险提示

加密货币合约交易风险很高，可能快速亏损。  
本程序只是辅助监听和执行信号，不保证盈利，也不能避免交易风险。

请务必先使用模拟盘或小资金测试。  
如果你开启实盘交易，所有盈亏和风险由你自己承担。
